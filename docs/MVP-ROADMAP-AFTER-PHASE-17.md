# MMSC MVP Roadmap After Phase 17

## Status

Accepted planning sequence. This document changes no application behavior.

## Current state

Phase 17 — Notification Center is completed. All completed Phases 0–17 retain their repository status, numbering, implementation, and historical documentation.

## Next implementation phase

Phase 18 — Attendance Operations, Manual Check-In & Exception Handling has subsequently been completed. It extends the authoritative attendance foundations from Phases 8, 9, and 14. Phase 24 is now the next planned MVP phase.

## MVP completion sequence

After Phase 18, MVP development proceeds directly through:

1. Phase 24 — Events and Calendar Experience
2. Phase 25 — Reporting and Analytics Expansion
3. Phase 26 — Security Hardening
4. Phase 27 — PWA Optimization
5. Phase 28 — Operational Administration
6. Phase 29 — Super App Integration Polish

These phases must operate against implemented domains only. They must not create placeholder Clinic, Library, Laboratory, Credits, or Canteen features or reports.

## Deferred Post-MVP modules

- Phase 19 — Clinic Management
- Phase 20 — Library Management
- Phase 21 — Computer Laboratory Management
- Phase 22 — MMSC Credits / Wallet Foundation
- Phase 23 — Canteen and Cafeteria Management

These modules remain part of the long-term product and retain their phase numbers. Deferral does not alter their architectural obligations: they must use the Multi-Experience Super App architecture, centralized authentication and RBAC, authoritative MMSC identities and credentials, shared APIs, defined domain ownership, and the MMSC design system.

## MVP definition

The initial MVP includes the implemented Core Platform, Security/RBAC, HRIS, Teacher Management, SIS, Enrollment, Academics, Employee and Student Attendance foundations, Administrative Dashboards, Teacher Portal, Grading, Student Portal, Offline-first Attendance Terminal, Registration and Admissions, Public Applicant Intake, Parent / Guardian Portal, and Notification Center. Phase 18 adds operational/manual attendance handling. Phases 24–29 then complete Events and Calendar, Reporting and Analytics, Security Hardening, targeted PWA Optimization, Operational Administration, and integration polish.

Clinic, Library, Computer Laboratory, MMSC Credits, and Canteen are Post-MVP expansion domains.

## Scope boundary

The original roadmap update was documentation and planning only. Phase 18 was subsequently implemented and is documented in `docs/phases/PHASE-18-ATTENDANCE-OPERATIONS.md`; this historical sequencing document does not itself define later implementation.
